## Как разморозить

1. Запустить WSL-дистрибутив `DwemerAI4Skyrim3`, сервер CHIM.
2. Если CHIM обновлялся — `tools/after_update.sh` (не `install.sh`, не `tools/apply_playthrough_patch.sh`).
3. `php tools/test_court.php` → ALL OK; `php tools/test_ext.php` → 107 прошло, 2 старых падения.
4. Проверка в игре по разделу 5 `ROADMAP.md` — её не делал никто с 2026-10-06.
5. Дальше — часть 1 Нарратора по `docs/design/god-narrator.md`.
