## 1. Что можно сказать в игре

| «Объявляю закон…» · «какие законы» · «отмени закон 2» | Законы только в твоём холде | ✅ |
| «Включи / выключи безнаказанность» | Стража не видит твоих преступлений | ✅ |
| «Собери всех на пир» · «гости, сюда» · «расходитесь» | Гулянка на два игровых дня, Игры, еда, питьё | ✅ |
| «Заткнись» · «все замолчите» | Тишина | ✅ |
| «Назначаю X казначеем / палачом / шутом / виночерпием / хускарлом / советником» | Должность; хускарл ходит за тобой | 🔧 |
| «Кто при дворе?» · «снимаю X с должности» | Список; снятие | 🔧 |
| «Верни как было» | Отмена последнего приказа, приговора или задачи Нарратора (30 мин) | 🔧 |

### Суд и казна
| Скажи | Что будет | |
|---|---|---|
| «Суд над X» | X приводят и держат перед тобой, двор молчит | ✅ |
| «Приговариваю к казни» · «к тюрьме на 3 дня» · «штраф 500 в казну» · «оправдан» | Приговор исполняется, суд закрыт, слух по холду. «Тебе грозит казнь» — не приговор | 🔧 |
| «Сколько в казне?» · «налог 20%» | Налог с торговцев каждые 15 мин | ✅ |
| «Выдай Бренуину 300 из казны» · «положи в казну 1000» · «куда ушли деньги?» | Выплата любому; внести можно не больше, чем при себе | 🔧 |

На казни осуждённый выходит из всех фракций, чтобы родня и стража не напали на тебя. *Это необратимо.* Детей никогда не казнят, не сажают, не раздевают и не натравливают на них стражу.

| «Сангвин, выпьем» · «спорим на 100, что…» · «подари что-нибудь» · «повесели нас» · «уймись» / «шали» | Эль, пари (через 2 мин ×2 или пакость), дар с подвохом, Роза Сангвина при большой милости | 🔧 |

Каждый бог говорит своим голосом: Шеогорат, Хермеус Мора и Клавикус Вайл — голосами из игры, Аркей — голосом Арнгейра, Сангвин — пьяницы, Мара и Кинарет — женскими. 🔧

Сами по себе: Сангвин безобидно шалит раз в 25–40 минут, боги спорят о твоих делах, NPC иногда молятся вслух. Часто докучать богу — он рассердится и откажет.

## 3. Перед игрой

- **Перезапусти Skyrim полностью** — мост v16 (торговля, цены) подхватывается только при запуске.
- Если после перезапуска перестали работать **все** приказы — откати мост: в `MO2\mods\TES God Console Report\Scripts` переименуй `AIAgentQuestProgressionBridge.pex.bak-v15` в `AIAgentQuestProgressionBridge.pex` (с заменой) и перезапусти игру.
- Ключ OpenRouter: лимит $2 без сброса, истекает 13.10.

## 4. Проверка в игре (по порядку)

1. «Суд над Назимом» → «Приговариваю к тюрьме на 3 дня». Ждём: стража ведёт в темницу.
2. «Суд над X» → «Приговариваю к казни». Ждём: стражник дерётся с X; родня X **не** нападает на тебя, на детей никто не нападает.
3. «Выдай Бренуину 300 из казны», «Куда ушли деньги?».
4. «Назначаю Йорлунда хускарлом» → он идёт за тобой; «Снимаю Йорлунда с должности».
5. Нарратору: «Сангвин, выпьем», «Кинарет, пошли дождь», «Аркей, исцели меня».
6. Адрианне: «Скуй мне стальной меч» → через 10 мин курьер, меч и письмо.
7. Белетору: «Давай поторгуем» → окно торговли.
8. «Верни как было» после приказа.

Что не сработало — скажи, разберу по логу.

1. Плагины `ext/<name>/` ставлю сам: `php -l` → `tools/test_court.php` → выкладка → коммит → applied-log → пуш.
2. «Да» владельца: ядро CHIM, SQL с изменением данных, сейв, ENB и визуал. Мост Papyrus — с резервной копией прошлой версии.
3. Непроверенное — 🔧, пока владелец не подтвердил в игре.
4. ID и имена функций — только из индекса игры и каталога Papyrus.
5. После обновления CHIM: `tools/restore_core.sh`, проверить STT (`grep -c gigaam remote_faster_whisper.py`).
