# Локальная модель (запасной вариант без облака)

**Что стоит (2026-10-04):** Qwen3.5 4B, GGUF Q4_K_M, только текст (модуль зрения mmproj убран в
`G:\AI\LM Studio\_unused\`), LM Studio на Windows, сервер `0.0.0.0:1234`.

| | |
|---|---|
| Видеопамять | 3,4 ГБ при контексте 14 336 (измерено nvidia-smi; с модулем зрения было бы ~4,1) |
| Скорость | запрос NPC на 9,3 тыс. токенов — 0,9 с (кэш промпта тёплый), первый — 4-5 с; игра в это время была закрыта |
| Вызов инструментов | есть, родной; агент в сухом режиме исполнил «уволить Кая, назначить Вонгвилда» за 8 шагов |
| Мышление | **обязательно выключать**: `reasoning_effort: "none"`. Иначе весь `max_tokens` уходит в размышление и ответ пустой. `/no_think`, `enable_thinking`, `reasoning.enabled` не действуют |

**Куда подключена**
- `ext/tes_agent/worker.php`: последняя в списке моделей — берётся, когда облако не ответило
  (нет ключа, денег, сети). Первой: `--local` или `conf_opts TES_AGENT_LOCAL_FIRST = 1`.
- CHIM: коннектор id 20 «Local Qwen3.5 4B (LM Studio)», драйвер `openaijson`
  (`settings/local_llm.sql`). С 2026-10-04 04:20 по требованию владельца стоит ВО ВСЕХ слотах профиля
  (основная, быстрая, мощная, экспериментальная, форматтер, дневники, запасная) и первой у агента —
  `settings/local_llm_everywhere.sql`, там же команды возврата на облако.

**Качество (честно):** для агента годится; реплики NPC заметно хуже Gemini — путает, от чьего лица
говорит, коверкает имена («Садиа»), морализирует. Это запасной вариант, не замена.

**Запуск:** Windows — `powershell -File tools\local_llm.ps1` (сервер + загрузка модели с нужным
контекстом). После перезагрузки ПК адрес хоста из WSL может смениться: `bash tools/local_llm.sh`.

**Почему не меньше/не больше:** Qwen3.5 2B — 1,8 ГБ, но слабее в русском и в длинном промпте CHIM
(~10 тыс. токенов); 9B (уже скачана, Q8) — 10 ГБ, с игрой не влезет.
