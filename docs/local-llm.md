# Локальная модель — пробовали и убрали (2026-10-04)

Ночью 2026-10-04 владелец попросил локальную модель с вызовом инструментов на ~3 ГБ видеопамяти,
через час — вернуть облако и локальную удалить. Запись оставлена, чтобы не проходить это заново.

- Ставили Qwen3.5 4B (GGUF Q4_K_M, без mmproj) в LM Studio, сервер `0.0.0.0:1234`, коннектор CHIM id 20
  (драйвер `openaijson`). 3,4 ГБ VRAM при контексте 14 336 — в 3 ГБ не влезла.
- Мышление выключается только `reasoning_effort: "none"`; иначе весь `max_tokens` уходит в размышление
  и ответ пустой.
- Агент (`ext/tes_agent`) на ней работал; реплики NPC заметно хуже Gemini 2.5 Flash (путает, от чьего
  лица говорит, коверкает имена).
- Из WSL хост виден по адресу шлюза (`ip route`), LM Studio нужно запускать с `--bind 0.0.0.0`.

Удалено: коннектор 20, файлы модели, SQL и скрипты запуска. В `worker.php` остался выключенный путь
`--local` / `TES_AGENT_LOCAL_FIRST` на случай повторной попытки.
